# 🔮 Decision Oracle

A minimal decision-making web page that helps users stop overthinking and get instant Yes/No answers.

## 🚀 Live Demo
👉 https://piyush-3113.github.io/DecisionOracle-help-you-decide-/

## ✨ Features
- Random Yes / No decision
- Decision statistics tracking
- Keyboard shortcut support (Enter)
